Bladefall Dialogue Editor

Return to Bladefall

Every line a player can read is listed here: what people say, your reply choices, object and relic descriptions, signs, notices, quest and side-story text, shop text, titles and on-screen prompts. Edits save in this browser, separately from campaign data, so Full Reset does not erase them. Reload Bladefall to see them (an open game tab picks them up the next time a line is shown). Use Export JSON to hand your edits to an agent, who can write them back into the source — each edit carries its file and line.
