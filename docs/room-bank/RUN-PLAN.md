# Original five-run plan

Recovered from the user's original run instructions on 8 October 2026. This is the governing sequence; later feedback refines quality and execution, not the purpose of each run.

| Run | Purpose |
| --- | --- |
| 1 | Discover meaningful new combinations of existing systems, without adding mechanics or entities. Unused precision-course and merge-pitch systems are eligible. |
| 2 | Build rooms around proposed new movement tech, primarily exploring the additions rather than familiar tech. |
| 3 | Do the same for new entities. |
| 4 | Combine Runs 2 and 3: new movement techniques interacting with new entities and the existing game, primarily exploring the new additions. |
| 5 | Synthesize lessons from all preceding runs into rooms using the full interaction of old/new mechanics and old/new entities. |

Room counts are flexible, chosen for distinct meaningful opportunities rather than a fixed quota. Keep equal Base and Fractured additions. Rooms from any run may be selected for the final game; a later run is not automatically better.

Runs 1–3 followed their respective themes, with execution, bypass and difficulty issues revised after user feedback. Run 4 has been reviewed; approvals and revisions are recorded in the current Superrooms guide. Four additional continuous superrooms extend this review cycle. Run 5 is now built as four compact rooms and four superrooms, balanced between Base and Fractured; see [the current guide](RUN-5.md). The staged [original plan](RUN-5-PLAN.md) is retained as context.

The earlier Run 4 proposal emphasized familiar objects changing jobs. That remains a useful design principle, but it is subordinate to Run 4's actual new-movement × new-entity purpose. Broad all-system synthesis belongs to Run 5.

The user subsequently requested another set after Run 5. [Run 6](RUN-6.md) continues the full-synthesis approach with four more Base and four more Fractured rooms; it does not replace or redefine the original five-run sequence.
