BLADEFALL — ASCEND
Willow Studios · Sample 0.53.0 · Windows x64

Extract the ZIP, open the Bladefall folder and run Bladefall.exe.
Keep Bladefall.pck next to Bladefall.exe. Godot does not need to be installed.
This Windows build is unsigned. It has been exported and its game pack checked
on macOS; it has not yet been play-tested on a Windows PC.

Arrows: move/aim · Space: jump · D: dash · A: climb/carry · W: strike
R: retry · Escape: pause. Controllers and remapping are also supported.

Progress saves automatically on this device. Settings > Export Save makes a
portable backup containing your Garden, checkpoints, preferences and controls.
Use Settings > Import Save in the Windows, Mac or browser version to move your
progress there. Import replaces that device's existing progress.

Play in browser or find other downloads at https://bladefall2dsample.pages.dev

Garden rewards, Fractured routes, Core keepsakes, individual checkpoints and
existing save migrations are the same as the Mac and browser sample.
Credits and the Godot license are included in this folder.
