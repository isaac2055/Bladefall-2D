# Reused Bladefall audio

All audio in this prototype is copied byte-for-byte from the existing Bladefall project. `data/audio.json` records each original path and SHA-256. The Outskirts uses Midnight Field; Black Woods uses Watchful Greenwood. Ambience, effects, effort takes and all spoken lines are existing recordings. No dialogue was rewritten, no voice synthesis was called and no ElevenLabs credits were spent.
